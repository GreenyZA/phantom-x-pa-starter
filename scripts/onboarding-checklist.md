# Onboarding checklist

Use this while bind completes. Check off each item only after verified.

- [ ] Kit cloned, README read
- [ ] Secrets paths registered (no values committed)
- [ ] Health smoke probe green (or red items accepted in writing)
- [ ] Runtime wired (model/tool path documented)
- [ ] Interview completed (one answer per line)
- [ ] Persona profile produced (`templates/persona-profile.md`)
- [ ] Day-one task list produced (max seven items)
- [ ] Bind note signed off by owner
- [ ] Billing/customer scope explicitly in scope or out of scope
- [ ] Mail + money still in draft-only mode
- [ ] Nightly report destination confirmed (dated markdown note)
- [ ] Escalation contact captured

No item may be checked off before the owner signs it off.
